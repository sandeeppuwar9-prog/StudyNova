# StudyNova

A modern educational Flutter app.

## Current Features
- Home dashboard
- Bottom navigation
- Books section
- AI Chat placeholder
- Notes placeholder
- Profile placeholder
- Featured books
- Categories
- Search UI

## Run
1. Install Flutter.
2. Run `flutter pub get`.
3. Run `flutter run`.
